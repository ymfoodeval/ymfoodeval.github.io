설정

명단·권한은 SharePoint '명단' 리스트가 원본입니다. 이 화면은 현재 불러온 값을 확인하는 용도이며, 명단을 바꾸려면 SharePoint에서 직접 수정한 뒤 아래 '다시 불러오기'를 누르세요.

계정 · 소속팀 · 직급 · 그룹 · 평가대상 · 팀장여부 · 분포예외 · 1차/2차/3차평가자는 SharePoint '명단' 리스트 값 그대로입니다. 로그인한 계정의 이메일이 명단의 '계정' 열과 일치해야 본인 인식·권한 판정이 됩니다.
고정 정책 (ver2)
· S등급 = 별도재원 고정 — S는 팀 예산 가중평균(B=100%) 계산에서 완전히 제외되며, 전사 경영성과 재원에서 별도 지급됩니다. 팀 분포·예산은 훼손되지 않습니다.
· S 부여 권한 = 대표이사 단독 — group이 '대표'인 사람만 S를 선택할 수 있습니다.
· S 상한 = 전사 인원의 5% 이하 — 초과 시 시스템이 경고합니다.
· 팀 성과(팀장 평가) 상한 = A(110%) — 팀장(=팀 평가) 대상에는 S를 부여할 수 없습니다.
· 표준분포 — 고정 비율(예: 20/60/20) 없이 인원수 기준 가중평균이 B(100%)로 수렴하는지만 검증합니다. 팀은 서로 묶지 않고 팀별로 개별 검증합니다.
· 평가대상(ver2) = 임원·팀장·관리직 — 생산직·도급직은 전용 평가방식 확정 전까지 이번 라운드에서 자동 제외됩니다.
· 생산팀 평가라인 — 당분간 팀장이 소속 인원을 전담 평가합니다. 서브팀장 자리는 명단에 공석으로 준비돼 있으며, 이름이 배정되면 자동으로 평가라인에 반영됩니다.
· 신사업팀 등 예외팀 — forceExempt로 지정된 팀은 강제분포·예산중립 검증을 적용하지 않고 등급을 자유롭게 부여합니다.
· 휴직·중도 입퇴사자 — 해당 평가기간 내 재직 이력이 없으면 이번 라운드는 건너뛰고 다음 평가기간으로 이월합니다.
연동 구조
흐름: Microsoft 계정으로 로그인(Azure AD/MSAL) → Microsoft Graph API로 SharePoint 사이트 ymfoodcorp.sharepoint.com/sites/ymfoodeval의 명단·어필시트·평가기록·설정 4개 리스트를 직접 읽고 씁니다. 제출은 즉시 SharePoint 리스트에 행이 생성·수정되며(별도 Power Automate 불필요), 평가자에게는 브라우저 mailto 링크로 알림 초안이 열립니다. 데이터는 이 화면에서 CSV/JSON으로 내보낼 수 있습니다.

권한 판정: 로그인한 계정의 이메일을 '명단' 리스트의 계정 열과 대조해 자동으로 결정됩니다 — 평가대상=예 → 어필시트 탭, 1차/2차/3차평가자에 본인 이름이 있으면 → 평가자입력 탭, 그룹=대표 또는 '설정' 리스트의 관리자 값에 본인 이메일 포함 → 집계·예산/설정 탭.

딥링크: 어필 제출 시 ?role=eval&evaluator=…&target=…&period=… 링크가 생성돼, 평가자 계정으로 로그인해서 클릭하면 해당 피평가자 화면이 바로 열립니다.

전제 조건: Azure AD 앱 등록에서 API 권한 Sites.ReadWrite.All에 대한 관리자 동의가 필요하며, 앱의 SPA 리디렉션 URI가 실제 배포 URL과 일치해야 합니다.
